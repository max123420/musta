# Production-readiness checklist

- [ ] Licensed clinical review of workflows, forms, terminology, and alerts
- [ ] Sudan legal/privacy and data-processing approval
- [ ] PostgreSQL migrations and tenant isolation
- [ ] TLS, secure cookies, CSRF, MFA, secret manager, rate limits, security headers
- [ ] Independent penetration test and threat-model review
- [ ] Encrypted offsite backup and tested restore/incident exercise
- [ ] Sync worker, conflict-review UI, central ingest, and observability
- [ ] Lab/radiology/pharmacy/billing/appointment modules with acceptance tests
- [ ] Accessibility, RTL/LTR, performance, localization, and end-to-end tests
- [ ] Operational support, training, change control, and rollback plan
