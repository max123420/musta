# Clinic user manual (pilot)

1. The clinic administrator completes first setup using a temporary password, then replaces it through the planned account-management workflow.
2. Reception registers a patient with Arabic or English name and consent preference.
3. A doctor drafts an encounter, reviews it, and signs it. Signed records must not be altered; document corrections as addenda once that workflow is implemented.
4. Cashiers record only verified payments. An invoice remains partially paid until its verified amount covers its total.
5. The clinic administrator reviews the sync dashboard; queued or failed entries must be investigated, never manually overwritten.

The current user interface is a setup screen plus API documentation. Role-specific reception, clinical, laboratory, pharmacy, billing, and reporting screens are not yet implemented.
